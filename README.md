# Laoshi Growth Audit

**Live → https://eddieatadapty.github.io/laoshi-flow-rebuild/**

Five ideas to turn more Laoshi users into subscribers, each built into a clickable version of Laoshi's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Let the first character be the payoff | +10–20% CR to purchase |
| 02 | Use the answers you collect | +10–20% CR to purchase |
| 03 | Make the 3-day trial feel safe | +8–15% CR to purchase |
| 04 | Make the annual saving impossible to miss | +10–15% ARPU |
| 05 | Catch the people who close the paywall, with three offers | +10–15% ARPU |

Every price, rating and feature comes from Laoshi's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Laoshi. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
